# 🛍️ E-Commerce Store

A full-stack e-commerce web application developed using HTML, CSS, JavaScript, Node.js, and Express.js. The project allows users to register, log in securely, browse products, view product details, add items to the cart, and place orders through a clean and responsive interface.

---

## Features

- User Registration
- Secure User Login with JWT Authentication
- Password Encryption using bcryptjs
- Product Listing
- Product Details Page
- Shopping Cart
- Quantity Management
- Checkout System
- JSON-based Data Storage
- Responsive User Interface

## Installation

Clone the repository

```bash
git clone https://github.com/itxtayyaba12/ecommerce-store.git
```

Go to the project folder

```bash
cd ecommerce-store
```

Install dependencies

```bash
npm install
```

Start the server

```bash
node server.js
```

Open your browser and visit

```
http://localhost:3000
```
